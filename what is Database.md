# What is a Database?

A database is an organized collection of data that is stored electronically and can be accessed, managed, and updated efficiently.

## Simple definition
A database is like a digital filing system where information is stored in a structured way so that it can be searched and retrieved easily.

## Examples of data stored in a database
- Student records
- Customer information
- Product inventory
- Orders and payments
- Employee details

## Why databases are used
Databases help in:
- storing large amounts of information
- retrieving data quickly
- keeping data organized
- updating records safely
- reducing duplication and errors

## Basic database structure
A database usually contains:
- Tables: a collection of related data
- Rows: individual records
- Columns: fields or attributes

Example:

| StudentID | Name     | Age | City     |
|----------|----------|-----|----------|
| 101      | Alice    | 20  | Delhi    |
| 102      | Bob      | 22  | Mumbai   |

Here:
- StudentID, Name, Age, City are columns
- Each row is a student record

## Database vs DBMS
- Database: the actual data and its structure
- DBMS (Database Management System): software used to create, manage, and access the database

Examples of DBMS:
- MySQL
- PostgreSQL
- Oracle
- SQL Server
- SQLite

## Types of databases
1. # Relational databases: 
store data in tables with rows and coulumns, store data in structured form.

Example:
- student table
- course table
- marks table
- products table

2. # NoSQL databases/ non-relational database : 
store data in flexible formats like documents, key-value pairs, or graphs, JSON
Example: 
- mongodb
- cassandra
- redis

## database management system (DBMS)
A DBMS is software used to create, manage, and access a database

EXAMPLE:

## In summary
A database is a structured system for storing and managing data so that it can be used efficiently by applications, businesses, and users.

> A database is essential in modern systems because almost every digital application relies on stored data.
